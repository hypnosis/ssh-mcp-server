# assets/

Знак проекта: серверная стойка и ключ рядом с ней.

| Файл | Для чего |
|---|---|
| `icon-master.png` | исходник, 1254×1254 — из него собирается всё остальное |
| `icon-512.png`, `icon-128.png`, `icon-48.png` | светлая тема: чёрный знак на прозрачном фоне |
| `icon-dark-512.png`, `icon-dark-128.png`, `icon-dark-48.png` | тёмная тема: тот же знак белым |

Размеры не правятся руками — пересобираются из исходника:

```bash
./scripts/build-icons.sh
```

Ссылки на эти файлы стоят в `server.json`, поле `icons`, и ведут на `raw.githubusercontent.com`.
Переименование файла ломает опубликованную запись в реестре MCP, поэтому имена не меняем.
