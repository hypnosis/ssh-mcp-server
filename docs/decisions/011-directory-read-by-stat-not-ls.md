# 011. Каталог читается `find` и `stat`, а шаблон разбирает сервер, а не его оболочка

## Context

`ssh_file_list` звал `ls -lah` и отдавал его вывод как есть. Описание при этом обещало
«every entry with its size, mode, owner and modification time» — то есть поля, которых в
ответе не было. Разбирать вёрстку `ls` оставалось вызывающему: ровно та работа, ради
снятия которой инструменты и заведены.

Вывод `ls` — это вёрстка, а не данные, и ломается он в четырёх местах сразу:

- размер округлён (`1.2K`), точного числа байт в нём нет;
- год печатается только у старых файлов, у свежих — время; получается два разных формата
  в одной таблице;
- колонки расходятся между BusyBox и coreutils;
- имя с переводом строки становится двумя строками таблицы, и разбор по строкам считает
  его двумя файлами.

Замер на обоих контейнерах перед выбором формы команды:

| Что | BusyBox | coreutils |
|---|---|---|
| `stat -c` с `%s %Y %U %G %a %F %d %i %n` | есть | есть |
| `find -mindepth`, `-maxdepth`, `-exec … +` | есть | есть |
| `find -printf` | **нет** | есть |
| `readlink` с несколькими аргументами | **нет**, ровно один | есть |
| `%N` (имя с целью ссылки) | без цели и без кавычек | с целью, в кавычках |
| жалоба на закрытый каталог | `find: /path: …` | `find: '/path': …` |

## Decision

**Поля печатает `stat`, обход делает `find`.** Одна команда, два прохода:

```
LC_ALL=C find <путь> -mindepth 1 [-maxdepth 1] [-name <шаблон>] \
  -exec stat -c '<маркер>%s|%Y|%U|%G|%a|%F|%d:%i|%n' {} +
```

**Запись начинается маркером, а имя стоит последним.** Разбор режет вывод по маркеру, а не
по строкам, поэтому перевод строки внутри имени остаётся внутри имени; всё, что перед
именем, имеет твёрдую форму, а имя забирает остаток записи целиком — вместе с `|`, если он
там есть.

**Цель ссылки берётся против пары «устройство:инода».** Второй проход печатает ключ и
следом ответ `readlink`. Имя в этой паре не участвует: переводы строки носит имя, а ключ не
носит. `%N` не годится — на BusyBox он цели не печатает вовсе.

**Шаблон разбирает `find`, а не оболочка сервера.** Он едет закавыченным значением `-name`.
Прежняя защита — экранирование каждого знака обратным слэшем — была нужна ровно потому, что
шаблон раскрывала оболочка, и это была единственная дыра, где значение обязано было
остаться незакавыченным.

**Команда идёт под `LC_ALL=C`.** Отказ разбирается по тексту жалобы, а сервер в другой
локали ответит тот же отказ словами, которых разбор не знает.

**Отказ у двери и отказ внутри обхода — разные исходы.** Первый оставляет нечего отвечать и
поднимается ошибкой с текстом сервера. Второй оставляет всё остальное: записи собраны, а
дверь названа в `unreadable`. Список, короткий ровно на интересный каталог, иначе читается
как полный.

## Alternatives

**Разбирать `ls -lah`.** Дёшево и не меняет вид ответа. Отвергнуто: размер приезжает
округлённым, время — в двух форматах, а имя с переводом строки разваливает разбор — то
самое семейство дефектов, которое уже ловили при смене транспорта.

**`find -printf`** дал бы всё одной командой и без второго прохода. Нет у BusyBox — значит
половина лаборатории и весь класс встраиваемых устройств остаются без листинга.

**Один проход и `readlink` через `sh -c` внутри `-exec`.** Вложенные кавычки внутри команды,
которая под `sudo` закавычивается второй раз, — известный источник дефектов; выигрыш в один
обход того не стоит.

**Отдать цель ссылки против имени.** Тогда пара «имя → цель» упирается в то же самое имя с
переводом строки, от которого весь разбор и уходит.

## Consequences

- Ответ объявлен схемой: `entries[]` с `name`, `type`, `size`, `mode`, `owner`, `group`,
  `mtime`, `target`, рядом `unreadable` и `truncated`. Инструментов со схемой стало 15.
- Текст ответа больше не вывод `ls`: колонки собираются из тех же полей.
- Шаблон, начинающийся с дефиса, больше не отказ, а шаблон; шаблон без совпадений — пустой
  список, а не провал команды. Оболочка сервера в этом пути не участвует вовсе.
- Два прохода дают две одинаковые жалобы на одну закрытую дверь — они схлопываются в одну.
- Маркер записи остаётся условностью: имя, содержащее сам маркер, разбор разрежет неверно.
  Цена принята — та же условность держит разделители секций в аудите.
