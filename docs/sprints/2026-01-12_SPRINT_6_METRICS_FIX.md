## 📋 ОПИСАНИЕ

Исправление багов в Connection Pool метриках:
1. Отрицательные значения `activeConnections` (баг)
2. Бесконечный рост метрик без сброса (потенциальная утечка памяти)

## 🐛 ПРОБЛЕМЫ

### Проблема 1: Отрицательные activeConnections
**Симптом:** `Active Connections: -1` в статистике  
**Причина:** Счетчик `activeConnections` в метриках рассинхронизировался с реальным состоянием пула  
**Решение:** Вычислять `activeConnections` динамически из `this.connections.size`

### Проблема 2: Бесконечный рост метрик
**Симптом:** Метрики (`totalConnections`, `totalCommands`, `cacheHits`, `cacheMisses`) растут бесконечно  
**Причина:** Метрики никогда не сбрасывались, накапливались за всё время работы сервера  
**Решение:** Автоматический сброс метрик при закрытии всех соединений (сессия закончилась)

## 🎯 ЗАДАЧИ

### 1. Исправить отрицательные activeConnections ✅
**Файл:** `src/managers/connection-pool.ts`  
**Время:** 15 минут

**Решение:**
```typescript
getStats() {
  // Вычислять динамически из размера Map
  const activeConnections = this.connections.size;
  
  return {
    ...this.metrics,
    activeConnections, // Override с вычисленным значением
    connections,
  };
}
```

**Результат:**
- ✅ `activeConnections` всегда корректное (0 или больше)
- ✅ Синхронизирован с реальным состоянием пула

### 2. Добавить автосброс метрик при закрытии сессии ✅
**Файл:** `src/managers/connection-pool.ts`  
**Время:** 20 минут

**Решение:**
```typescript
private cleanupIdleConnections(): void {
  // ... закрытие idle соединений ...
  
  // Если pool пустой → сброс метрик
  if (this.connections.size === 0 && toClose.length > 0) {
    logger.debug('All connections closed, resetting session metrics');
    this.resetMetrics();
  }
}

private resetMetrics(): void {
  this.metrics.totalConnections = 0;
  this.metrics.totalCommands = 0;
  this.metrics.cacheHits = 0;
  this.metrics.cacheMisses = 0;
  this.metrics.reconnects = 0;
}
```

**Результат:**
- ✅ Метрики сбрасываются когда все соединения закрыты
- ✅ Метрики живут только в рамках текущей сессии
- ✅ Нет бесконечного роста (нет утечки памяти)
