# TD-07. Проигравший в гонке установок получает сырой текст `mv`

**Дата:** 2026-08-05
**Статус:** ✅ закрыт 2026-08-14
**Откуда:** CORE_10, список потенциальных багов (замер живьём); проверено по коду в CORE_11, задача 1.3

---

Две установки в один путь: одна коммитит, вторая отказывает, оба дерева целы. Сохранность
не нарушалась — плохо читался отказ. Он уезжал наверх текстом самой утилиты:

```
Error: Command failed (exit 1): mv -T -- '/tmp/racetest' '/tmp/.bak-66e690407492.racetest'
       — mv: cannot stat '/tmp/racetest': No such file or directory
```

Из такого текста не понять ни того, что в путь писал кто-то ещё, ни того, что ничего не
изменено.

## Что сделано

Отказ замены объясняется словами вызывающего. Причину спрашиваем у сервера, а не
разбираем текст ошибки: набор утилит и язык сообщений на разных серверах разные. Цель
исчезла между разведкой и заменой — значит её увёл соседний вызов; цель на месте, а
занять её не удалось — значит сосед успел поставить туда свою копию. Оба исхода названы
по-разному, потому что различаются последствия: в первом ничего не изменено, во втором
подготовленная копия не встала на место, и её адрес человек читает в предупреждениях.

Текст утилиты не потерян — он идёт после `Details:`.

Замок через `mkdir` не заводили: он добавляет состояние, которое надо снимать после
аварий, а ничего к сохранности не прибавляет — она держится на порядке переименований.

## Чем доказано

Замер живьём: два параллельных `ssh_upload` каталога в один путь на debian.

**До:** `Error: Command failed (exit 1): mv -T -- … — mv: cannot stat …`

**После:**

```
Error: /tmp/racetest was moved away by another install into the same path while this one
was replacing it. Nothing was changed by this install. Details: Command failed (exit 1):
mv -T -- '/tmp/racetest' '/tmp/.bak-2f6e757b0157.racetest' — mv: cannot stat …
```

Победившая установка в обоих замерах отвечает обычным успехом со сверкой хэшей.

Сторожа — юниты `installer.test.ts`: цель исчезла, цель на месте (причину не подменяем),
путь занят чужой копией. Проверены мутацией: «любой отказ объявляется гонкой» и «исход
путают» — обе красят тесты.
