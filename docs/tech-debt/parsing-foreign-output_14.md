# TD-14. Разбор чужого вывода теряет строки и путает колонки

**Дата:** 2026-08-13
**Статус:** 🟡 открыт, в v2.1
**Откуда:** приёмка, находки AC-13, AC-26, AC-27, AC-28

---

Четыре места, где вывод системной утилиты разбирается по счёту колонок или по позиции
разделителя. Пока формат совпадает с ожидаемым, всё верно; как только сервер печатает
иначе — строка молча пропадает или встаёт не в ту графу.

**Файлы в списке дисков** (`ssh_snapshot`, alpine и router). Из `df -h | grep -E "^/dev/"`
берутся не те колонки, и в поле точки монтирования оказываются файлы, подмонтированные
внутрь контейнера:

```
Disk:
  /etc/resolv.conf 5.7G     / 487.1G   (1%)
  /etc/hostname 5.7G     / 487.1G   (1%)
```

**Кэш под именем «доступно»** (`ssh_audit_baseline`, `src/tools/audit-tool.ts:411-420`).
`available` берётся как последняя колонка строки `Mem:`. На `free` из procps старше
примерно 2014 года такой колонки нет вовсе, и последней идёт `cached`.

**Том с длинным именем исчезает** (`ssh_audit_baseline`, `src/tools/audit-tool.ts:396`).
`df -hT` переносит запись на две строки, если имя файловой системы длинное — overlay-пути
docker, длинные адреса NFS. Обе половины отбрасываются условием `cols.length < 7`, и том
пропадает из отчёта: ни в разделе, ни в `NOT CHECKED`, ни в красных флагах.

**Слушатели IPv6** (`ssh_snapshot`, `src/tools/snapshot-tool.ts:270-280`). Порт вырезается
из адреса через `cut -d: -f2`: для `0.0.0.0:443` это работает, для `[::]:4847` второе поле
пусто и запись отсеивается. На стендах не видно — там каждый слушатель IPv6 дублируется на
IPv4, и порт попадает в список с другой строки.

## Что сделать

Разбирать по имени колонки из заголовка, а не по номеру, и по последнему двоеточию, а не
по первому. Строку, которую разобрать не вышло, показывать в `NOT CHECKED` — сейчас она
исчезает бесследно, и это ровно тот класс, который чинили в чанке 3.

## Почему не сделано сразу

Все четыре — мелочи по решению о границах релиза. Первые две воспроизводятся живьём,
третья и четвёртая подтверждены по коду: серверов с длинными именами томов и с одним
только IPv6 в лаборатории нет, а без замера правка была бы функцией без живой проверки.
